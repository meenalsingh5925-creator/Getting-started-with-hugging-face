# Getting-started-with-hugging-face
This repository contains my work and projects completed during the **Getting started with Hugging Face** workshop .

## Workshop Work
The repository includes:
-1: Introduction to Hugging Face Transformers
-2: Building an AI Text Assistant
    Text generation using GPT-2
    Sentiment analysis using DistilBERT
    Building an interactive interface using Gradio

## AI Text Assistant
As part of the workshop, I build an AI text assistant tha can:
- Analyze the sentiment of user-provided text
- Generate a continuation of given text
- Provide an interactive user interface using Gradio

### Models used
- **GPT-2** - Text Generation
- **DistilBERT (SST-2)** - Sentiment Analysis
